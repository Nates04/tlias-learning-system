# tlias-learning-system

## 项目简介
基于 Spring Boot + MyBatis + hostman的tlias智能学习辅助系统后端。

## 技术栈
- Java 11
- Spring Boot 2.7.x
- MyBatis
- MySQL
- JWT
- Lombok

## 开发工具
- IDEA
- Postman（接口测试）
- Git / GitHub

## 功能模块
- 部门管理（增删改查）
- 员工管理（增删改查 + 分页）
- 登录认证（JWT）
- 文件上传
- 拦截器/过滤器
- 操作日志记录

## 运行方式
1. 导入 IDEA
2. 配置 MySQL 数据库
3. 修改 application.properties
4. 运行 EmsApplication.java
